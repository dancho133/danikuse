# Danikuse design system (diagrams)

The project's diagram skin, created for `diagram-design` and stored as the saved profile `danikuse` (`~/.diagram-design/profiles/danikuse.md`); this repo selects it via the `.diagram-design` marker (`profile: danikuse`).

| Role | Value | Notes |
|---|---|---|
| paper | `#faf6ef` | warm bone, never pure white |
| paper-2 | `#f1eadd` | container fill |
| ink | `#2a2320` | warm charcoal |
| muted | `#65584c` | secondary text, default arrows |
| soft | `#716357` | sublabels, boundary labels |
| accent | `#b3401e` | ember; 1–2 focal elements per diagram, matches the coral hero in product screenshots |
| accent-tint | `rgba(179,64,30,0.08)` | focal fill |
| link | `#2e5aa8` | HTTP/API arrows |

Typography: Instrument Serif for page titles, Geist 600 for node names, Geist Mono for technical sublabels and labels. Mono is for technical content only. First diagram in this system: [architecture.html](architecture.html).
