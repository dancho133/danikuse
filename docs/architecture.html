Architecture · Danikuse design system

Danikuse: you pick the surface, one module does the work

Как читать схему

Ты сам выбираешь поверхность именем команды: /danikuse-my — твой Brave, /danikuse-agent — браузер агента, /danikuse-desktop — компьютер с курсором. Дальше один модуль исполняет задачу нужным движком справа.

Видимость

По умолчанию всё видно. Фон нужен только браузеру агента: слово «в фоне» добавляет --hide, у фона отдельные сессия и профиль. Твой Brave и десктоп не прячутся никогда.

Доказательства, не обещания

Каждое действие падает в Run Folder: JSON, скриншот, время — только локально. AGY и ExtremeRouter на схеме больше нет: это помощники разработки в окружении агента, а не часть продукта.
