# Danikuse Launch Demo Script (20 Seconds)

Voiceover script for the 5-beat Danikuse launch demo video.
Storyline and blueprint defined in `danikuse/launch/motion-survey.md`.
Verified with `vendor-slopmonster/tools/deslop.py`.

---

## Beat 1: Hook (00:00 - 00:04.5)
- **Visual**: Scattered browser drivers and scrapers collapsing into one unified Danikuse entry point.
- **Voiceover**:
> Browser agents and desktop scrapers are fragmented. Danikuse unifies them.

## Beat 2: The Engines (00:04.5 - 00:10.0)
- **Visual**: Automation Browser (lightweight 10 MB profile) alongside Personal Brave attached over extension bridge.
- **Voiceover**:
> A light automation browser for daily tasks, and your personal Brave attached with no debug port.

## Beat 3: Safety Architecture (00:10.0 - 00:15.1)
- **Visual**: Autonomous reads and DOM inspection pass freely. Mutating operations require Confirm Mode, while payment and credential inputs hit an emphatic Hard Stop red barrier.
- **Voiceover**:
> Confirm Mode asks before mutating. Payments and passwords hit an instant Hard Stop.

## Beat 4: Verifiable Evidence (00:15.1 - 00:20.1)
- **Visual**: Terminal displays `npm run benchmark` passing 5 of 5 tasks. A structured JSON response contract card slides out with run evidence.
- **Voiceover**:
> Every action returns one verifiable JSON contract. No evidence, no done.

## Beat 5: Install and Call to Action (00:20.1 - 00:24.2)
- **Visual**: PowerShell installation terminal running `./install.ps1`. Apache-2.0 license badge and GitHub repository link.
- **Voiceover**:
> Install with PowerShell. Apache two on GitHub.
